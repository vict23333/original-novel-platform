# 原创小说读写平台

基于 Spring Boot 与 Vue 的原创小说读写平台，围绕作者创作、内容审核、读者阅读和评论互动展开。

当前已完成第一批正式代码：读者/作者注册、登录、个人资料维护、退出登录和服务端角色鉴权。作者与管理员入口已建立，其余业务模块逐步实现。早期 HTML 原型中的业务数据与 AI 交互仍为模拟。

## 技术方向

Spring Boot、Vue 3、Element Plus、MySQL、MyBatis-Plus、JWT、大模型 API。

## 功能范围

| 使用端 | 功能模块 |
| --- | --- |
| 用户端 | 注册登录、小说浏览检索、在线阅读、书架收藏、评论互动 |
| 作者端 | 作品发布、章节编辑、AI 辅助创作、作品数据查看 |
| 管理员端 | 用户信息管理、作品审核、评论管理、分类标签管理 |

保留全部 13 个模块，按创作、审核、阅读与收藏的核心流程逐步实现。

## 需求与原型

- [功能范围与验收草案](01_需求与设计/功能范围与验收草案.md)：完整模块、验收示例与待细化的业务规则。
- [核心页面低保真原型](01_需求与设计/原型/核心页面低保真原型.html)：发现作品、小说详情、在线阅读、我的书架、作者编辑、内容审核六个页面。

将 HTML 文件下载后用浏览器打开，无需安装依赖；点击导航切换页面，可体验阅读设置、收藏及模拟创作等操作。它用于需求讨论，不能作为正式系统功能已实现的证明。
