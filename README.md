# 原创小说读写平台

基于 Spring Boot 与 Vue 的原创小说读写平台，围绕作者创作、内容审核、读者阅读和评论互动展开。

当前 v0.13 已跑通作者新建作品、编辑章节、提交审核、管理员处理、读者检索与分章阅读。保留 v0.1 的注册登录、个人资料和服务端角色鉴权；阅读页支持字号、背景设置，并新增书架收藏与章节、段落进度保存。已新增小说/章节评论、回复、点赞与管理员评论删除；新增热门/收藏/新书/更新榜、连载完结筛选、同题材推荐和作者数据面板；已加入 AI 续写/润色的配置接口、预览采用与撤销，已完成 DeepSeek 本机配置及真实续写、全文润色和预览采用/撤销验收；已补齐用户查询、资料维护、账号启停、分类标签维护与作品归类，并统一后台导航。v0.8 新增本地草稿恢复、专注写作、TXT 导出入口、章节序号建议与页码直达。早期 HTML 原型中的交互仍为模拟。

v0.12 重整发现首页、独立书库、角色导航、阅读设置、正文与 AI 双栏编辑和后台布局；修复目录翻页改变阅读起点、清空未发表评论的问题。保留查询与页码的网址恢复、失败重试及页面按需加载。前端 0.12.0，后端沿用 0.10.0，没有新增依赖或数据库表。见 [界面设计](02_项目源码/docs/界面与交互设计_v0.12.md)与 [v0.12 验证记录](02_项目源码/docs/验证记录_v0.12.md)。

v0.13 新增作者创作资料工作台：总纲、世界规则、文风、角色卡和本地取名；章目标随草稿保存，空白新章可按目标组织前文引用，确认后生成候选。前后端均为 0.13.0，V7 新增三张私有表。见 [创作设计与接口](02_项目源码/docs/创作工作台设计与接口.md)及 [验证记录](02_项目源码/docs/验证记录_v0.13.md)。本轮没有额外调用 DeepSeek，新上下文成稿质量仍待真实验收。

## 技术方向

Spring Boot、Vue 3、Element Plus、MySQL、MyBatis-Plus、JWT、大模型 API。

## 功能范围

| 使用端 | 功能模块 |
| --- | --- |
| 用户端 | 注册登录、小说浏览检索、在线阅读、书架收藏、评论互动 |
| 作者端 | 作品发布、章节编辑、AI 辅助创作、作品数据查看 |
| 管理员端 | 用户信息管理、作品审核、评论管理、分类标签管理 |

保留全部 13 个模块，按创作、审核、阅读与收藏的核心流程逐步实现。

## 需求与原型

- [功能范围与验收草案](01_需求与设计/功能范围与验收草案.md)：完整模块、验收示例与待细化的业务规则。
- [核心页面低保真原型](01_需求与设计/原型/核心页面低保真原型.html)：发现作品、小说详情、在线阅读、我的书架、作者编辑、内容审核六个页面。

将 HTML 文件下载后用浏览器打开，无需安装依赖；点击导航切换页面，可体验阅读设置、收藏及模拟创作等操作。它用于需求讨论，不能作为正式系统功能已实现的证明。

本地新增 18 部原创演示短篇、36 章和题材插画封面，内容与来源说明见[演示书库](02_项目源码/database/演示数据说明.md)。演示数据需要单独导入，不随普通启动自动生成。

本地另导入 107 部外部参考小说，原有 21 部作品保留，当前共 128 部。参考正文与账号映射仅留本机，来源、转换及重复导入规则见[参考书库说明](02_项目源码/database/参考书库导入说明.md)。页面已优化电脑窄窗口布局，书库与排行榜在 700px 以上保持多列。
