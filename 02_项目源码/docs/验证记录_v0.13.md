## 数据与收尾

临时创建一个作者账号和一部未发布合成作品，API 创建两章，Edge 主动保存一章空白草稿，共三章；验收后全部软删除，账号停用。未发布作品和其私有资料留作测试记录，没有公开发布。清理重新登录获取有效令牌，没有复用 Edge 退出前的旧令牌。

对既有原创演示作品《云海铸剑人》，只在创作资料为空时补入标为演示的大纲、世界规则、文风和两张角色卡，未改正文及公开版本。前 50 部公开作品的完整返回与本轮开始一致，总数仍为 128。没有模型付费请求。

- 未实现摘要记忆、AI 生成大纲/人设、关系图及自动审稿，不列为通过。
- 未执行压力、公网部署、完整跨浏览器或正式用户可用性研究。
- 后端请求发送后再遇资料变化，候选会被拒绝，但供应商可能已经计费；失败不会自动重试。

本记录反映开发验收结果，版本发布状态以仓库提交历史为准。课程历史 Word 和教师材料未修改。本机配置、密钥、日志、验收账号和截图不进入公开提交范围。

## 本人验收

1. 登录作者，在“我的作品”进入“创作资料”，保存大纲、世界规则和文风。
2. 在“角色与取名”维护角色；取名候选只填表，需要点击保存才入库。
3. 新建章节，填写本章目标，选择角色，点击“按本章目标起草”。展开查看引用内容。
4. 确定资料可发送给所配置的模型后，点击“确认资料并生成候选”。这一步会使用 API 额度；本轮自动验收没有执行它。
5. 修改候选后采用，再保存草稿。已有正文时试用续写、选段润色或扩写，检查前后文是否连贯。
