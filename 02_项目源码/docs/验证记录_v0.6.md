## 后端检查内容

- 未登录返回 401；读者与管理员调用作者接口返回 403；他人章节和删除章节返回 404。
- 待审或版本过期返回 409；AI 等待期间另一页保存后，旧生成结果也返回 409，不改新稿。
- 输入为空、超长、模式不合法或额外指定端点时返回 400，调用供应商之前拒绝。
- 模拟生成成功或超时后原草稿不变，失败释放并发槽；状态接口不暴露地址或密钥。
- 本机 HTTP 桩实际检查请求格式与鉴权头；验证正常返回、长度截断标记、429、拒绝重定向、无效 JSON、空响应、超大响应及超时。
- 每账号并发、冷却期、单进程总并发和释放行为有自动化验证。

测试 HTTP 桩仅绑定本机回环地址，返回内容包含“测试模拟，非真实 AI”。验收结束已停止该进程并撤销临时配置；正常实例使用未配置状态。

## 浏览器检查

在真实浏览器中完成作者登录、章节编辑与实际后端调用，未用前端拦截伪造业务成功：

1. 生成续写后原文不变；修改预览、追加、撤销成功。
2. 全文润色后保存并刷新，内容仍保留；清空预览后输入框仍可编辑，空预览不可采用。
3. 使用键盘选择正文的两个字符，确认仅将该片段用于润色；采用、撤销保留其他正文。
4. 生成后手动改正文，旧预览采用按钮禁用；放弃预览不删除修改后的原文。
5. 模拟供应商 429，界面出现明确提示，正文保持不变；慢响应期间保存按钮禁用。
6. 390px 视口没有横向溢出；AI 面板截图已实际查看，按钮、预览和提示可见；监测到的页面异常为零。
7. 恢复未配置状态后，页面明确提示 AI 未连接，生成按钮禁用，普通保存仍可用；重新检查状态正常。
