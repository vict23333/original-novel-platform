## 修复与检查范围

- 公共读取使用 `public_*`，防止草稿标题、分类、正文、序号提前公开；阅读接口同时检查所属作品状态。
- 章节草稿与公开序号分别唯一；软删除释放序号并保留审核关系。
- 编辑页与阅读页对路由加载结果进行请求序号核对，避免较慢响应覆盖新页面。
- 审核页显示题材名称，读取详情时取得最新版本；公开快照可展开检查。
- 测试中创建的临时审核管理员已停用并撤销会话，原有管理员配置保持不变。

## 尚未验证或实现

未执行性能压测、完整浏览器兼容性矩阵、生产部署、互联网安全测试或故障注入；32 项测试并非全系统覆盖率，也不能推导吞吐量或用户承载规模。实际 MySQL 并发检查仅验证一次相同版本的双写竞争。

书架、账号阅读进度、评论、热门榜单、作品统计、AI 调用，以及用户/评论/分类标签维护尚未实现。当前阅读偏好仅保存在浏览器。批量调整章节顺序、恢复软删除章节、审核历史全文浏览界面也未提供。

## 复现

在工程目录先停止服务，再执行 `./scripts/build.ps1` 和 `./scripts/dev.ps1 -Action Start`。构建运行隔离测试；按[工程 README 验收顺序](../README.md#验收顺序)复现页面流程。测试命令不向普通数据库注入演示账号、作品或审核数据；需要通过页面自行创建内容。
