# v0.10 书架检索与代码解析验证记录

本轮在 v0.9 上增加个人书架书名搜索、已读/未读筛选、最近阅读排序，并建立[代码解析目录](代码解析/README.md)。未新增数据库迁移。

## 接口与规则

`GET /api/me/bookshelf` 保留原默认行为，新增可选参数：

| 参数 | 可用值或限制 |
| --- | --- |
| keyword | 最多 100 字符，去首尾空白后按公开书名匹配字面子串 |
| status | ALL（默认）、READ、UNREAD |
| sort | ADDED（默认）、RECENT_READ |
| page / size | 原规则：页码 1—100000，每页 1—50，默认 1 / 12 |

已读表示存在已保存阅读进度，不表示已读完。最近阅读按进度更新时间倒序，未读排在后面，同时间按收藏时间与作品编号倒序。筛选在数据库中先于分页执行，总数使用同一条件。只查询令牌所属账号的书架，不能用参数选择其他账号；下架条目保留但不提供可读链接，搜索不会查到未审核的新草稿标题。

前端修改条件后点击查询生效，查询/重置回到第一页；翻页、移出后刷新、失败重试沿用已应用条件。无匹配结果与尚无收藏分别提示。移出最后一页的全部条目时回到剩余有效末页，阅读记录仍保留。

- 前端 Node 测试 31 项通过，Vite 生产构建通过。新页面交互通过实际浏览器验证，不把旧纯逻辑测试数量当作新增页面测试。
- 真实 MySQL：163 次初始 HTTP 检查通过。合成读者收藏 13 部已有公开作品，保存其中一部进度，核对已读 1 部、未读 12 部、最近阅读排序、跨页、组合查询和另一个账号隔离。
- Tabbit：登录返回书架、两页切换、未提交筛选不影响翻页、空结果、重置、已读/未读组合、书名检索、最近阅读排序、模拟网络失败保留结果和重试通过。
- 1440、1024、768、390px 下均无横向溢出。
- 桌面截图请求 12 秒超时，未完成截图视觉验收；上述为实际交互和 DOM 尺寸检查。
- 验收后移除合成账号的 13 条测试收藏、停用两个测试账号，保留测试阅读进度和管理记录。最终 150 次检查通过，128 部公开作品信息与本轮前一致。首次清理使用已退出的旧令牌得到 401，辅助脚本重新登录后完成清理，未改变鉴权规则。

代码解析为 Markdown，包含目录树、13 模块映射、调用链、状态图、AI 时序图、13 张业务表说明和答辩要点；链接直接指向实际源码。课程原始模板与历史 Word 不修改，不含账号密码及本机密钥。

## 边界

搜索目前只支持书名，未增加作者名搜索、批量删除、阅读时长或读完比例。没有进行大规模书架压力测试；每条恢复信息仍有额外数据库查询。DeepSeek 真实生成及 TXT 下载落盘确认延续前轮待办。本轮先交付本地修改，未执行 Git 提交或推送。
