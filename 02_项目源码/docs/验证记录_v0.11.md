## 浏览器验收

使用 Tabbit 操作实际页面和现有本地 MySQL 数据；没有创建、修改或删除业务记录。检查时公开书库总数为 128。

- 查询流程：未提交条件不影响翻页；刷新恢复第三页；组合筛选后进入详情并浏览器返回；刷新保留组合条件；无结果提示；重置；过期页码自动回到第 11 页。均通过。
- 错误恢复：浏览器临时拦截分类请求，书库仍能展示；解除拦截后重试成功。临时拦截查询请求，旧列表清空，解除拦截后按原条件重试成功。均通过。产生的两条网络失败是主动注入的验收场景。
- 排版：390、768、1024、1440 像素窗口均无横向溢出，书库分别为 1、2、2、3 列。
- 视觉截图：Tabbit 截图等待 30 秒超时，未取得图片，未完成截图目视验收；上面的布局结论来自真实页面 DOM 尺寸与列数检查。
- 生产预览：首页实际请求两个初始 JS 文件，没有提前请求作者/管理员页面；点击排行榜与书籍详情后加载对应分包；未登录进入作者、管理员地址均跳到带返回目标的登录页。通过，未发现页面 JavaScript 异常。
