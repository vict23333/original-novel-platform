# 代码解析阅读入口

这份资料用于理解、维护和答辩，依据 v0.13 源码编写，课程作业仍单独保存在课程目录中。

最新创作资料、前文预览和空章起草见 [创作工作台设计](../创作工作台设计与接口.md)，源码跟踪可读完整解析第 9 节。

最新布局与阅读偏好逻辑见 [界面与交互设计](../界面与交互设计_v0.12.md)，实际操作见 [v0.12 验证记录](../验证记录_v0.12.md)。

刚接触代码可以先读 [书库查询与按需加载](书库查询与按需加载.md)：用搜索、翻页和刷新的实际操作，理解表单、网址、接口请求与页面显示如何配合，再读完整代码解析。

先读[项目构成与代码解析](项目构成与代码解析.md)。它包含目录结构、13 个功能模块的源码对应、登录到数据库的调用过程、审核状态和公开快照、书架与阅读进度、评论与统计、AI 原稿保护，以及测试和排错方法。

推荐分三次阅读：第一次读第 1—4 节，弄清工程如何启动、请求如何到后端；第二次读第 5—10 节，对照页面跟踪业务；第三次读第 11—13 节，动手验证并练习答辩。文中的类名和方法名可在编辑器中搜索，链接指向实际源码，不依赖容易随修改失效的行号。

资料不含本机账号、密码、API 密钥或私人路径。后续代码调整时应同步更新对应章节；历史验证记录只证明当轮实际执行的检查。
