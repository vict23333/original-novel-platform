## 本轮修复

1. 登录后的安全返回路径增加书架、作品详情和阅读页，仍限制为明确的站内路由。
2. 阅读保存携带正文指纹与版本，服务端同时验证位置边界；旧正文或旧进度均返回明确冲突。
3. 刷新同章按账号记录恢复；变更正文后回到章首；用户移出书架时保留进度。
4. 开发脚本在停止进程后等待实际退出，避免 MySQL 接受 shutdown 后尚未退出就再次启动。修复前曾出现 readiness 失败，修复后连续停止启动通过。
