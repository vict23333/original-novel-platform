# AI 辅助创作设计与配置

2026-09-24 更新：当前服务商已选定 DeepSeek，配置步骤与专用请求选项见[写作保护与 DeepSeek 接入](写作保护与DeepSeek接入.md)。本机尚无密钥，真实生成未验收；下文保留通用兼容接口设计。

## 范围与使用流程

v0.6 实现 FR-08：作者在已保存的章节中进行剧情续写、全文或选段润色。保留原有 13 模块，用户管理与分类标签维护继续按计划实现。本轮不增加付费订阅、自动发布或 AI 任务历史模块，不修改数据库结构。

作者先保存一次章节，在正文中写入素材。续写使用当前编辑区末尾最多 6000 字符；润色优先使用正文中选中的片段，否则使用全文，超过 6000 字符时要求选择较短片段。可填写最多 500 字符的创作要求。界面在生成前说明素材会发送给已配置的外部服务；不自动发送账号信息、小说简介、其他章节或整本作品。

结果只进入预览区，支持二次编辑。续写可追加到正文，润色替换原选区或全文。采用不自动保存、不自动送审。作者须检查内容后按既有流程保存和送审。可撤销最近一次采用；如果采用后又手动改稿，不直接撤销以免丢失新内容。正文已改变时不允许旧预览覆盖；离开有修改、预览或正在生成的页面会提示。

## 后端配置

默认关闭 AI，没有配置时明确显示“AI 服务尚未连接”，普通写作仍可用。产品不内置模拟模式。测试中的模拟响应只用于验证，不代表真实模型能力。

使用 Windows 开发脚本时，在项目的 `.runtime/ai.local.json` 中填写下列配置（该文件始终被 Git 忽略）：

```json
{
  "enabled": false,
  "apiUrl": "",
  "apiKey": "",
  "model": "",
  "timeoutSeconds": 45
}
```

选择服务商后填写完整的 Chat Completions 请求地址、密钥与模型标识，将 enabled 改为 true，然后正常 Stop、Start。地址必须为 HTTPS，不接受查询参数或内嵌账号密码。模型名称以服务商当前可用列表为准。本接口采用 `messages`、`model`、`stream: false` 与 `max_tokens`，解析 `choices[0].message.content` 和 `finish_reason`，协议参考 [DeepSeek 官方 Chat Completions 文档](https://api-docs.deepseek.com/api/create-chat-completion/)。兼容协议并不保证任意服务商的全部模型可用，配置后仍须实测。

也可设置后端进程的环境变量（优先于本地 JSON）：

| 变量 | 用途 |
| --- | --- |
| AI_ENABLED | true 启用，默认 false |
| AI_API_URL | 完整的生成端点，不自动拼接路径 |
| AI_API_KEY | 服务商密钥，仅后端读取 |
| AI_MODEL | 服务商支持的模型标识 |
| AI_TIMEOUT_SECONDS | 整体生成等待上限，1—90 秒，默认 45 秒 |

开发脚本仅将这些变量传给后端，启动 Vite 前移除，并在退出脚本时恢复调用方原有环境。不要将密钥放进 `VITE_*`、源码、截图、报告或 Git。无需在聊天中提供密钥。更新配置需重启后端，页面“重新检查连接状态”只检查配置是否齐备，不会产生外部调用，也不宣称已验证账户余额或网络连通。

测试仅通过显式配置允许本机 HTTP 模拟端点；正常配置不开放明文 HTTP。本机当前未配置真实服务商，因此真实生成质量、付费额度及真实 API 联调待完成。

## 接口与业务保护

| 接口 | 行为 |
| --- | --- |
| GET /api/author/ai/status | 返回 available、model、cooldownSeconds，不返回密钥或端点 |
| POST /api/author/chapters/{id}/ai | 输入 version、mode、text、instructions；返回 content、truncated、model |

mode 只允许 CONTINUE 或 POLISH。请求正文不接受额外的 userId、密钥、端点或模型覆盖。AUTHOR 角色在服务端校验，读者/管理员不得调用作者接口；他人的章节及删除章节返回 404。正在审核或版本不匹配返回 409。允许发送本人未保存的编辑片段；生成前后均核查已保存章节版本。外部请求不持有数据库锁或事务，不写入正文，最终保存仍受既有版本校验约束。

每个账号同时最多一个请求，两次开始至少间隔 20 秒；单进程最多四个并行调用。限制存在内存，重启清空，不作为跨实例配额、计费或持久化限额。禁用状态不调用供应商。没有自动重试，避免异常时产生重复费用；用户主动重试仍可能由服务商计费。

外部调用有连接超时和整体超时，限制响应体为 128 KiB、结果为 6000 字符；不跟随重定向。空响应、拒绝或异常结束返回固定错误；达到 token 长度上限时明确标记可能未完整，供作者检查。返回内容作为纯文本显示，不执行 HTML。错误、日志不包含供应商原始正文、作者素材、密钥或请求地址。

网络失败不会改动原稿。离开页面会中止客户端等待；服务端已经发出的请求未必能取消，可能继续消耗供应商额度，不能宣称点击离开即停止计费。预览只在当前页面内存保留，刷新可能丢失，需先采用并保存。
