# DeepSeek 真实服务联调记录

联调时段：2026-10-28 至 2026-10-29。本次在既有 v0.11 前端、v0.10 后端上完成配置和验收，没有新增依赖、修改业务代码或迁移数据库。

## 配置与授权

用户在本机隐藏输入窗口填写密钥，配置保存在被 Git 忽略的本机运行目录，由后端读取。启动脚本在启动前端前清除 AI 环境变量。本文、截图和公开源码不包含密钥。

使用 DeepSeek 官方 Chat Completions 端点、`deepseek-flash` 模型、非流式输出和非思考模式。配置与请求选项已按 [官方接入文档](https://api-docs.deepseek.com/zh-cn/)及 [Chat Completions 文档](https://api-docs.deepseek.com/zh-cn/api/create-chat-completion/)核对。

用户明确批准发送一段临时生成的原创短文及对应要求，进行一次续写、一次润色。两次请求均从 Microsoft Edge 页面发起，经过本项目后端调用真实服务；测试过程未使用模拟返回替代真实结果。

## 使用方法

作者进入自己已保存且未处于审核中的章节，填写正文或选中要润色的片段，在 AI 面板点击续写或润色。生成后先检查、修改预览，再追加或替换；需要保留时点击“保存草稿”，之后按正常流程送审。采用不会自动保存或公开。

两次生成开始至少间隔 20 秒。更换密钥或模型后需重启后端，配置状态只能证明字段齐备，实际是否可用仍以生成结果为准。
