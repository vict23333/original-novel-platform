# v0.5 发现作品与作者数据

## 范围与参考

借鉴已下载的 [novel](https://github.com/201206030/novel) 和 [novel-front-web](https://github.com/201206030/novel-front-web) 的产品组织：BookRankCacheManager 的点击/新书/更新榜、DbSearchServiceImpl 与 BookSearchReqDto 的组合筛选、BookServiceImpl.listRecBooks 的同类推荐，以及 BookRank.vue 的榜单入口。两份本地 LICENSE 为 Apache-2.0。本轮理解其功能后独立编写接口、SQL 和 Vue 页面，不复制其业务代码、界面素材或小说数据。

本轮细化 FR-02 浏览检索与 FR-09 作者统计：热门榜、收藏榜、新书榜、更新榜、连载/完结筛选、同题材推荐、真实日阅读去重、作者总览与单作品近七日趋势。沿用 13 模块范围；一次完整交付后再推进 AI、用户管理和分类标签维护。参考工程的充值订阅、新闻及复杂中间件暂不加入，避免改变免费原创平台的业务范围。

## 数据与口径

V5 仅新增 novel_read_day，不改 V1—V4 或原有数据。登录从 JWT 取身份，游客从当前浏览器会话随机 UUID 取身份，后端按带身份类型前缀的 HMAC-SHA256 派生 visitor_key，不使用 IP、真实邮箱或设备指纹。使用后端 JWT 密钥作带用途前缀的派生密钥；轮换密钥可能形成新的统计身份，需安排迁移或明确计数边界。原始匿名标识不落库。

唯一键为 (visitor_key,novel_id,read_date)，同一身份同一天翻章和刷新只记一次；游客转为登录按两种身份统计，不等同于自然人去重。自然日采用 Asia/Shanghai，时间戳为 UTC；近七日为今天及前六天。阅读页成功展示公开章节才请求记数，预览和书籍详情不记数；失败不阻塞阅读，也不补造历史数据。客户端关闭存储时本页使用内存身份。

事务先锁小说再锁章节并使用 READ_COMMITTED，校验当前可公开后查重写入，与下架和章节删除使用相同锁顺序。保留唯一键作为最终约束。不宣称反刷或高并发容量达标。

当前收藏数直接统计 bookshelf，有效评论数排除已删正文（包括根和回复）。公开章节数和字数仅统计当前可读公开快照；字数为正文字符数（含空白），不读取待审草稿。首次公开时间取作品首次审核通过记录；更新榜时间取当前可读章节的最新通过记录，草稿保存和驳回不触发更新。历史数据无审核时间时不伪造更新时间。

热门榜按近七日阅读、当前收藏、作品编号降序；收藏榜按收藏、近七日阅读、编号降序；新书榜按首次公开时间、编号降序；更新榜按公开章节最近通过时间、编号降序。榜单及同类推荐只含至少一章可读的公开作品；同类推荐排除当前书，按热门口径取四本，空集有明确提示，不声称个性化模型推荐。搜索可浏览尚未有公开章节的已审作品。排序参数只映射服务端白名单，关键词按字面值匹配。

## 接口

- GET /api/public/novels：keyword、categoryId、serialStatus、sort、page、size，增加公开统计信息，原分页结构兼容。
- GET /api/public/rankings：kind=POPULAR/COLLECTED/NEWEST/UPDATED，categoryId、serialStatus、page、size。
- GET /api/public/novels/{id}/discovery：公开统计与同题材推荐。
- POST /api/public/chapters/{id}/read-event：游客提交 anonymousId，登录用户使用服务器认证身份；返回 counted、readDate，不返回任何访客身份。无效令牌拒绝，不静默降级成游客。
- GET /api/author/stats：本人所有作品总览与近七日趋势。
- GET /api/author/novels/{id}/stats：本人单作品总览与趋势；他人返回404，读者/管理员不能借此绕过 AUTHOR 权限。

作者统计可含本人下架作品的历史计数，公开榜单实时排除下架内容。所有新增页面含加载、空数据、错误和重试状态，页面切换防止旧请求覆盖新结果。

## v0.11 查询恢复与 v0.12 独立书库

书库以 URL 保存已提交的 keyword、categoryId、serialStatus、sort、page，省略默认条件，固定每页 12 条；刷新、浏览器返回和复制查询链接均可恢复。表单编辑与已提交条件分开，搜索回到第一页，翻页使用已提交条件，重置清空条件。书库查询页码上限 100000，与接口一致；非法参数回退默认，过期尾页按服务端总数回到最后一页。

分类和书库请求独立，分类失败不阻塞找书；查询变化或离开页面时取消旧请求并防止迟到结果覆盖。加载期间清空旧卡片，失败保留 URL 条件并提供重试。接口、数据库筛选和计数口径不变。v0.12 书库独立为 `/library`，旧首页查询链接转发兼容。详情页“返回书库”进入默认书库，恢复来源查询使用浏览器返回。查询逻辑见 [v0.11 验证记录](验证记录_v0.11.md)，新布局和交互见 [v0.12 界面设计](界面与交互设计_v0.12.md)。
