# 写作保护与 DeepSeek 接入

v0.8 围绕已有 FR-07 章节编辑、FR-08 AI 辅助创作和 FR-02 浏览检索完善使用流程，不新增收费、社交或自动发布业务，不增加数据库迁移。交付目标是提高编辑恢复、章节创建和长目录查找的可靠性；真实 AI 质量验收仍需本机配置密钥。

## 章节编辑

- 新建章节调用 `GET /api/author/novels/{id}/next-chapter-number`，按未删除章节的最大序号加一建议，不再固定为第一章。接口核对作者归属，达到 100000 上限返回 409；建议不预占序号，保存时仍检查重复。
- 编辑标题、序号或正文后约 600ms 写入当前浏览器的本地备份，保存主体包括内容、服务器版本和时间。按账号及章节区分；未创建章节按所属作品区分。
- 刷新回来发现与服务器不同的备份时，显示恢复、导出和清除选项；未选择前不覆盖备份，也不自动保存服务器。
- 恢复前需确认。服务器版本已有更新时明确提醒核对，恢复只替换编辑区。后续保存仍由服务器检查版本，保存成功才清理本页对应的备份。
- 本地记录保留七天，过期记录在该编辑页再次打开时清理。清除浏览器数据、禁用存储、空间不足或未及完成备份可能导致无法恢复；不能替代服务器保存。公共电脑使用后应清除本地备份。本地备份不加密，也不会提交 Git。
- 写入前比较上次读取的记录，发现其他标签页已经修改时停止覆盖并提示导出或保存服务器。这是客户端冲突检测，不是数据库级跨标签事务；重要稿件仍以服务器保存和导出为准。
- 正在审核的章节不可从本地备份恢复，但可导出。尚未采用的 AI 预览不纳入正文备份。
- `Ctrl/⌘ + S` 保存服务器草稿；专注写作收窄编辑区并收起 AI 面板；实时显示不含空白字符数。
- “导出正文 TXT”导出当前编辑内容，“导出本地备份”导出未恢复的内容。使用 UTF-8 文本，保留段落并移除文件名路径字符，不自动公开。
- 保存、提交正在执行时阻止内部路由切换，避免接口返回后覆盖另一章节的编辑状态。正常保存新章节后跳转其固定编辑地址。

## 分页和登录来源

通用分页支持输入页码直接跳转，书库、排行榜、章节目录、作者列表和后台列表共用。只接受 1 至实际末页的整数，不一次加载完整长篇目录。新增排行榜、作者数据页的登录来源白名单，拒绝未知额外参数及外部地址。

## DeepSeek 本机配置

服务商已选定 DeepSeek。2026-09-24 核对[官方 Chat Completions 文档](https://api-docs.deepseek.com/zh-cn/api/create-chat-completion/)后，预填端点 `https://api.deepseek.com/chat/completions` 和模型 `deepseek-flash`，生成请求使用非流式输出、`max_tokens: 4096`。仅当目标主机恰为官方 `api.deepseek.com` 时附加 `thinking: {"type":"disabled"}`，用于短篇续写和润色；其他兼容服务商不附加该字段。

当前 `.runtime/ai.local.json` 无密钥、enabled=false，未调用真实服务。模型列表可能变化，后续以服务商账户可用模型及官方文档为准。

在项目目录执行：

```powershell
.\scripts\configure-deepseek.ps1
.\scripts\dev.ps1 -Action Stop
.\scripts\dev.ps1 -Action Start
```

配置脚本在本机提示隐藏输入 API key，写入被忽略的 `.runtime/ai.local.json`，不打印密钥、不发出网络请求。可用 `-Model` 指定其他当前可用的模型。也可手动编辑配置文件；不把密钥发送到聊天或写入前端。

重启后作者进入已有章节，页面先检查配置是否齐备；该状态检查不等同于服务端连通、账户余额或模型能力验证。使用本人原创的短段落点击“剧情续写”或“润色选段 / 全文”才会发起真实请求，服务商可能计费。采用后仍须人工检查、保存及提交审核。

HTTP 401/403 返回密钥或模型权限检查提示；402 提示余额不足；429 提示繁忙或额度问题；超时和其他异常保留原稿。不显示供应商原始错误、密钥或完整请求内容。真实质量和收费情况未作为测试通过项。

通用 AI 权限、限流和预览规则见 [AI 辅助创作设计与配置](AI辅助创作设计与配置.md)。
