# 本地参考书库

本地书库增加外部参考数据，用于验证检索、长目录、连续阅读和页面布局。这些小说不是本项目创作成果。作品简介标注“外部参考书库导入”、原作者及原分类，关联账号昵称带“参考导入”；真实用户和本人创作的作品不被覆盖。

## 来源及转换规则

来源为此前下载的 [201206030/novel](https://github.com/201206030/novel) 数据压缩包，固定代码版本 `3a9f2ef7de296d18530dd92e76df830389c1288a`。只解析包内 book_info、book_chapter、book_content 与 book_category 的数据；不向正式数据库执行整份上游 SQL，不导入上游用户、密码、新闻、友链、评分或历史点击量。

源包含 107 部小说、11,137 章；没有发现缺失正文。HTML 换行转换为普通段落，正文以纯文本显示。超过本系统 20,000 UTF-16 单元限制的章节按段落拆分，增加 23 个分段，最终对应 11,160 个可读章节，章节目录连续编号。一个空标题明确标记“原数据未提供标题”。四份简介里的联系方式已省略，小说正文不作剧情改写。

原书籍状态沿用源数据；“完结”不表示数据包必然包含全本，简介明确说明只有包内现存章节。源包提供的是旧封面路径，没有对应图片文件，因此沿用本系统已有题材插画，不请求失效的旧图片地址。

现有题材与源题材粒度不同，本次使用以下对应关系，同时在简介保留原分类：

| 源分类 | 本系统题材 |
| --- | --- |
| 玄幻奇幻、武侠仙侠 | 玄幻 |
| 都市言情 | 都市 |
| 历史军事 | 历史 |
| 科幻灵异、网游竞技 | 科幻 |
| 女生频道 | 其他 |

后续分类标签管理完善后可进一步细分。本次不修改既有类别或数据库结构。

## 执行与重复导入

导入器为 [import-reference.py](../scripts/import-reference.py)。它读取本机 `.runtime/reference-catalog.json` 中已整理并验证的数据，执行：

```powershell
python scripts/import-reference.py
```

使用正式业务 API 建立带参考标识的作者账号、新建作品与章节、提交章节审核、通过章节审核，最后公开整部作品。审核记录明确标注本地数据迁移。源码中的原 author_id 不作为本系统账号 ID，不关联到用户自己的作者账号。

`.runtime/reference-import/` 保存数据摘要、原记录与新记录的映射、逐章进度及随机账号凭据。重复运行复用映射，不新增重复作品；中断后可继续。已完成的章节不重新送审；内容发生修改或遇到驳回、下架时不擅自覆盖。四部独立作品并行，同一作品的操作串行。

数据包、小说正文、账号凭据、数据库和导入映射仅留本地，均不加入 GitHub。公开仓库只包含通用脚本及来源/转换说明；原先的原创演示集仍独立保留。

## 验证方式

导入后按映射逐章比对草稿正文与公开正文 SHA-256、标题、目录序号和审核状态；检查原书库内容不变、公开搜索分页无重复，并抽查首章、中间章、末章与拆分章节。读取接口不会上报阅读量；新导入作品的阅读和收藏从实际使用开始计数。完成结果记录在工程 README 及本地验收记录中。

本次结果：107 部作品、11,160 个目标章节全部完成；逐章哈希及 11,267 条审核记录验证通过，272 次只读 HTTP 检查包含 30 个实际正文样本。原有 21 部作品响应不变，当前公开总数为 128；重复执行导入器后新增作品 0、章节 0。新书/更新榜使用本系统实际审核公开时间，不冒用旧站的历史时间。未执行生产容量或长期稳定性测试。
