# 原创演示书库

`demo-catalog.json` 包含 18 部原创演示作品，每部 2 章，共 36 章。六类题材各 3 部，每类一部完结、两部连载；完结均指这两章组成的演示短篇完结。文本由本项目 AI 辅助编写，不是完整长篇网文，也不是从商业小说网站抓取的内容。

演示笔名按题材分别为青崖、南窗、夜航、星屿、故纸、拾光，实际账号昵称附“（演示）”。角色是独立测试作者，不与真实用户混用。不编造阅读量、收藏量、评论或点赞。

## 导入与重复运行

先按工程 README 启动本地后端，然后在工程目录用 Python 3 执行：

```text
python scripts/seed-demo.py
```

脚本只调用 `127.0.0.1:8081`，从本机被忽略的 `.runtime/settings.local.json` 读取管理员凭据。通过实际注册、作者建书建章、提交和管理员审核接口完成导入，没有绕过业务逻辑直接篡改审核状态。

导入状态、随机演示作者密码和资源 ID 只写入 `.runtime/demo-catalog-state.local.json`，绝不能公开。不要删除该文件后直接重复导入。相同数据集重跑会复用记录，验证内容一致并跳过已完成的步骤，不重复创建作品和章节；同名既有账号无法登录时停止，不重置密码。若演示内容被人工修改、驳回或下架，脚本停止并提示，不覆盖用户修改或审核决定。

普通构建和启动不会自动灌入数据；新环境需主动运行导入脚本。原有账号、作品、书架和阅读记录不会被清空。

## 查看方式

首页书库可通过题材和书名搜索，新增条目默认按作品 ID 倒序显示，每页 12 部。作品详情能进入两章正文，登录后可加入书架并保存进度。新增作品属于六位演示作者，因此不会出现在其他作者的“我的作品”列表中。

六张默认题材插画随前端静态资源提供，来源和开放使用说明见 [封面来源](../frontend/public/covers/README.md)。插画用于首页、详情、作者工作台与书架；没有新增作者图片上传功能，也没有更改数据库表结构。
